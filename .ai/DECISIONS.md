# DECISIONS / ADR

Дата первичных решений: 2026-10-22. Здесь фиксируются решения, альтернативы и причины.

## ADR-001. Изолированный новый репозиторий
**Принято**: изменения только в `looping`. `testing-hosting` читать как legacy-пример. Причина: не повредить работающие уроки. Не переносить прямые рабочие API_URL и client config.

## ADR-002. Thin HTML + shared modules + content data
**Принято**: сохранять URL `OGA/{number}/gaid.html` и домашние страницы как тонкие entrypoints, но фактические JS/TS, стили, рендерер, математические валидаторы и realtime вынести в `shared/`. Контент (станции, варианты, решения, цели) и theme tokens хранить отдельно. Выбор сборщика (например Vite) уточнить на стадии B. Нет 25 копий ядра.

## ADR-003. Общая модель комнаты, отдельно состояние ученика
**Принято**: navigation с явным `chapterIndex: 0`, `stationId`, `revision`; общие effects/board, персональные answers; source-of-truth при синхронизации — серверная модель событий + snapshots. Проверка роли/прав обязательна. Назначение комнаты не основано на открытом student code без контроля.

## ADR-004. Realtime provider
**Предварительный выбор для новой backend-платформы**: ASP.NET Core SignalR как будущий адаптер транспорта, совместимый с планируемой C#/PostgreSQL архитектурой; для UI и тестов обязательно `InMemoryTransport`. Старый код использует Firebase Realtime Database с `onValue`, транзакциями и `onDisconnect`. **Не принято** решение повторно подключать рабочий Firebase: доступ/правила/безопасность/инфраструктура не проверены. Финализировать адаптер и test environment на стадии B; если нет backend, это BLOCKER реального e2e, а не повод заявить о работающей синхронизации. Redis — позже по подтверждённой потребности, не обязательный prereq пилота.

## ADR-005. Векторная доска
**Принято**: независимый пакет `shared/board`, normalised coordinates, определяемые stroke IDs, сегментное попадание ластика, ревизии для reset/undo, неизменяемый event log. Не применять непрозрачные закрашивающие мазки поверх рисунка. Ctrl/Cmd+Z не должен ломать undo в текстовом поле.

## ADR-006. Утверждение качества
**Принято**: статус DONE только после реального запуска соответствующих тестов. Есть отдельно `NOT_VERIFIED`. Содержимое гигантских `gaid.html` старого репозитория пока не прочитано; аудит таких файлов нельзя обозначать полным.

## ADR-007. Пилот — ОГЭ №13
**Принято как план**: первый эталонный комплект №13 (неравенства): legacy содержит `пошагово.html`, `найди.html`, `собрать.html`, три ДЗ. Это позволит проверить шаги, числовую прямую, ошибки, игру и синхронизацию. До стадии C не создавать 24 другие комплекта с фиктивным содержанием.

## ADR-008. Источники и правообладание
**Принято**: собственная стилизованная графика, нейтральные мультяшные мотивы без чужих официальных кадров/логотипов; алгоритмы проверяются независимо от источника сюжета. ФИПИ — не заявлять авторство/номер прототипа без сверки.
