## Прочитанные фрагменты и механики
- `OGA/6/mix.html`: Firebase RTDB, игра с 1–2 учениками, генераторы дробей, `runTransaction` для состояния, `onValue` listeners, presence `onDisconnect`, доска и `Ctrl+Z`, очередь отправки результатов в GAS. Эти функции есть в коде; их корректность в браузере пока не подтверждена.
- `OGA/8/formula.html`: matching, игровые раунды, двухученический режим, Firebase подписки с явным `stopSessionListeners`, отдельное присоединение общей доски и pending result queue. `OGA/8/mix.html` — вторая отдельная реализация похожего транспорта.
- `OGA/9/correct.html` и `OGA/9/mix.html`: сценарии следующего шага/верно-неверно, игровые колоды, SVG-доска, поиск пересечений сегментов ластиком, авторизация через код, повторённые realtime helpers; используется также KaTeX в части legacy.
- `OGA/13/найди.html`: линии/интервалы и ошибка в неравенстве, `runTransaction`, board stroke IDs, `eraseAt`, `undoOwnStroke`, подписки с функцией `disconnectSubscriptions`. `пошагово.html`: шаги решения, интервалы, `segmentsCross`, `eraseAlong`, event cleanup. `собрать.html`: сборка решений и ещё одна реализация комнаты. Условие/решение каждого задания ещё требует math review.
- `OGA/18/correct.html`: модели геометрических рисунков, распределение карточек и turn state, pointer dragging, sync remote drag, очередь прогресса, stroke undo; `dz1.html` использует Canvas для рисунков.
- `OGA/6/dz1.html`, `dz2.html`, `OGA/8/dz1_new_system_v4.html`, `OGA/13/dz1.html`: клиентские наборы, MathJax по меньшей мере в 6/8, localStorage, отправка результатов через GAS. Они не содержат универсального transport API для платформы.

## Что пригодно как ПРОЕКТНЫЙ ПРИМЕР
- Небольшие тематические станции и интересные игровые экраны, 1–2 участника, смена ролей.
- Firebase subscription lifecycle, reconnect/presence, транзакционный счёт, очередь отправки результатов.
- Векторные штрихи вместо рисования закраской, геометрическое стирание по пересечению.
- Разные механики №13 — хороший вертикальный срез для эталона.

## Что НЕ переносить буквально
- Монолитные HTML, повторение realtime/board/login/result logic между страницами, встроенные working GAS URL/Firebase config.
- Client-side student code как эквивалент надёжной аутентификации.
- Локальные присвоения статуса «проверено/освоено» без серверного подтверждения и математического review.
- Встроенные base64-картинки и неподтверждённые права на мультяшные изображения.
- Смешение MathJax и KaTeX без единого контракта; повторяющиеся listeners и дубли idempotency.

## Не подтверждено / план закрытия
- Попытки `fetch_file` с line range на `OGA/{6,8,9,13,17,18}/gaid.html` вернули пустой content (все большие). Нужен доступ к полным bytes, ограниченный checkout, либо отдельный архив от владельца. Пока нельзя оценить содержательные главы этих гайдов.
- JS syntax, браузерное поведение и задержки legacy не запускались; возможные баги — только риски, не подтверждённые дефекты.
- Рабочие конфигурации Firebase/GAS из source намеренно **не скопированы**.
- Не выполнена сверка с актуальными кодификаторами ФИПИ.
